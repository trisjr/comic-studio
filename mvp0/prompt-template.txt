PAGE
│   ├── aspect_ratio / target_resolution
│   ├── reading_direction
│   ├── purpose · overall_mood
│   │
│   ├── LAYOUT
│   │   ├── rows[]  (y, h, panels[])   ← tổng h = 1.0
│   │   └── dominant_panel
│   │
│   ├── CONTINUITY  (khai báo MỘT lần, panel chỉ ghi delta)
│   │   ├── setting · time_span
│   │   ├── spatial  (ai trái / ai phải, không đảo)
│   │   ├── environment · wardrobe
│   │   └── progression  (beat từng panel)
│   │
│   └── TEXT_POLICY
│       └── render_text_in_image: false   ← G1-e: 100% overlay
│
├── CHARACTERS  (tối đa 2–3 nhân vật lặp lại)
│   ├── id  (dùng làm file ref: mvp0/refs/<id>.png)
│   ├── canonical_reference + reference_instruction
│   ├── silhouette_cue  (mỗi người MỘT dấu hiệu nhận dạng riêng, không trùng)
│   ├── identity  (gender, age, body_type — nêu chênh lệch tương đối)
│   ├── appearance  (hair, eyes, face, distinctive_features)
│   ├── outfit · personality
│
├── PANELS / FRAMES
│   ├── id · panel_index · row · column · relative_width · relative_height · shape
│   │   └── panel_index: số nguyên tuần tự TOÀN CHƯƠNG (không reset theo trang),
│   │       gán tại thời điểm page-plan, dùng làm tên golden-dataset/panels/panel-NNN/
│   ├── beat_type · emphasis · character_count (≤ 3)
│   ├── scene_delta  (chỉ điều khác so với CONTINUITY)
│   │
│   ├── CHARACTERS[]  (character_id, không dùng tên)
│   │   ├── position · pose · action
│   │   └── facial_expression · gaze · emotion
│   │       ← phải khớp với camera: nếu camera từ sau lưng thì không mô tả mặt
│   │
│   ├── CAMERA
│   │   ├── shot_type · camera_angle · camera_position
│   │   └── perspective · composition · focal_point
│   │
│   ├── LIGHTING · EFFECTS
│   │
│   ├── text_safe_zone[]  (x, y, w, h chuẩn hóa 0–1; không đặt mặt/focal detail)
│   │
│   ├── TYPESET  (không render vào ảnh, dùng cho stage overlay)
│   │   ├── dialogue[]  (speaker = character_id, text, bubble_type)
│   │   └── sfx[]
│   │
│   └── panel_purpose
│
├── STYLE  (khớp art direction dự án: 2D anime / manhwa lineart, cel shading)
│   └── color_language  (mỗi nhân vật một màu energy / accent)
│
└── NEGATIVE_CONSTRAINTS  (không lặp lại CONTINUITY; thêm cấm text + cấm swap silhouette cue)

# QUY TẮC ÁP DỤNG (đọc trước khi soạn page YAML)

- Vị trí file: mỗi trang soạn ra là MỘT file mvp0/pages/<page_id>.yaml, với
  page_id = "chNN_pageNNN" (NN = số chương 2 chữ số, NNN = số trang 3 chữ số),
  ví dụ mvp0/pages/ch01_page001.yaml. Nội dung tuân theo đúng cây trên.

- D4 — tên vs character_id: các trường PROSE (continuity.spatial, composition,
  panel_purpose, scene_delta, panel_purpose, dialogue text...) ĐƯỢC PHÉP dùng
  ten/ten_en của nhân vật cho tự nhiên. Các trường STRUCTURED sau đây BẮT BUỘC
  dùng character_id (id trong story-bible.yaml), KHÔNG được dùng tên:
    characters[].id · panels[].characters[].character_id ·
    typeset.dialogue[].speaker

- Mapping story-bible.yaml -> template (skill /mvp0-page-prompt chiếu 1:1,
  không qua LLM enhance trong script):
    nhan_vat[].id                              -> CHARACTERS.id
    nhan_vat[].ten_en                          -> CHARACTERS.name (prose dùng ten/ten_en)
    nhan_vat[].vai_tro                          -> CHARACTERS.role
    nhan_vat[].canonical_reference               -> CHARACTERS.canonical_reference
    nhan_vat[].silhouette_cue_en                 -> CHARACTERS.silhouette_cue
    nhan_vat[].gioi_tinh / tuoi                  -> CHARACTERS.identity.gender / age
    nhan_vat[].body_type_relative_en             -> CHARACTERS.identity.body_type
    nhan_vat[].canonical_reference_en.toc        -> CHARACTERS.appearance.hair
    nhan_vat[].canonical_reference_en.mat        -> CHARACTERS.appearance.eyes
    nhan_vat[].canonical_reference_en.khuon_mat  -> CHARACTERS.appearance.face
    nhan_vat[].canonical_reference_en.dac_diem_rieng
                                                  -> CHARACTERS.appearance.distinctive_features

    nhan_vat[].personality_en                    -> CHARACTERS.personality
    nhan_vat[].color_language_en                 -> STYLE.color_language
